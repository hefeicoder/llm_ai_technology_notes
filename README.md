## Notes on Data

The startup landscape slide mixes several types of valuation signals:

- completed private funding rounds
- reported private-market targets
- IPO targets
- acquisition or strategic transaction values
- undisclosed rounds where only raise size is public

Cards marked with `*` are not clean post-money funding valuations. Re-check fast-moving valuation data before publishing or quoting externally.
